# Tejash Sharma — Portfolio

This repository contains a full-stack portfolio scaffold for Tejash Sharma.

Structure created on feature/full-implementation branch. Add your content and replace sample data.

Features scaffolded:
- Frontend (Vite + React + Tailwind)
- Backend (Express + Mongoose)
- Authentication skeleton (JWT, bcrypt)
- Image upload skeleton (Multer + Sharp)
- Seed script with sample data

See frontend/README.md and backend/README.md for instructions.
